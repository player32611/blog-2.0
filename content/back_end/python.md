# Python

## 核心语法

### 字面量

|                |                                 |                      |
| :------------: | :-----------------------------: | :------------------: |
|    数字类型    |            整数(int)            |    10、18、-5、0     |
|    数字类型    |       浮点数/小数(float)        | 8.5、3.14、1.0、-3.5 |
|   布尔(bool)   |  表达显示生活中的逻辑，真或假   |     True、False      |
|  字符串(str)   |     描述文本的一种数据类型      |       "Python"       |
| 空值(NoneType) | 表示空或无值，仅包含一个值 None |         None         |
|    数据容器    |       存储多项数据的容器        | 列表/元组/集合/字典  |

通过 `str()` 语句可以将 int 类型的数据转为 str

通过 `int()` 语句可以将 str 类型的数据转为 int

::tip

通过 `type()` 语句来得到数据的类型，具体语法为：`type(要查看类型的数据)`

通过 `isinstance()` 检查数据是否属于指定的类型，返回的是一个 bool 知，具体语法为：`isinstance(数据, 类型)`

```python
print(type("Hello"))
print(type(10))
print(type(3.14))

num = 0.5
print(isinstance(num, int))
```

::

### 变量

```python

```

### 标识符

**标识符**是程序员在代码中为变量、函数、类等元素所起的名字

1. 只能包含字母，数字，下划线

2. 不能以数字开头

3. 不能使用关键字 True、False 等

4. 严格区分大小写

::tip

Python 命名规范

1. 见名知意

2. 多个部分使用下划线链接

3. 英文字母全小写

::

### 字符串

```python
# 双引号定义
s1 = "Hello"

# 单引号定义
s2 = 'Python'

# 三引号定义(多行字符串)
s3 = """
  定义:
    字符串
"""

s4 = "hello"
print("python: " + s4 + " , ")

# 通过 % 占位符的形式完成字符串和变量的快速拼接，% 表示占的位置，s 表示将变量转为字符串放入占位的位置
s5 = "user"
print("你好, 我是 %s" % s5)
print("你好, 我是 %s , 也是 %s" % (s5, s5))

# 也可以通过 f"内容{变量/表达式}" 的形式来完成快速格式化
name = "name"
print(f"你好，我是 {name}")
```

::warning

- 号也可以用来拼接两个字符串，但是无法将非字符串与字符串进行拼接(非字符串类型需要转换为字符串类型)

::

### 运算符

| 运算符 |  描述  |         举例说明          |
| :----: | :----: | :-----------------------: |
|   /    |  除法  | `10 / 5`，除法结果是小数  |
|   //   |  整除  | `10 // 3`，整除结果为整数 |
|  \*\*  | 幂指数 |  `10 ** 3`: 10 的 3 次方  |
|  and   | 逻辑与 |  同时成立才是符合条件的   |
|   or   | 逻辑或 | 只要有一个符合要求的即可  |
|  not   | 逻辑非 |         取反操作          |

::tip

- `//=`: 取整除赋值运算符

- `**=`: 幂赋值运算符

::

### 输入与输出

input 语句(函数)的功能就是获取键盘输入的数据

print 语句(函数)的功能就是将数据输出到控制台

```python
name = input("请输入姓名：")

```

### 条件判断

::code-group

```python [if]
if 要判断的条件:
  条件成立时，要执行对应的操作
```

```python [if...else]
if 要判断的条件:
  条件成立时，要执行对应的操作
else:
  条件不成立时，执行的操作
```

```python [if...elif...else]
if 要判断的条件1:

elif 要判断的条件2:
  条件成立时，要执行对应的操作2
```

```python [match...case]

  case 值2:
    逻辑2

    逻辑3
  case 值4:
    逻辑4

    默认逻辑
```

### 循环

::code-group

```python [while]
while 条件表达式:
  循环体语句
# 以下可选
else:
  条件为False，循环正常结束时执行
```

```python [for]

  循环体代码
# 以下可选
else：
  循环结束时，执行的代码
```

::

::tip

range 语句

作用：生成指定规则的数字序列

`range(end)`: 获取一个从 0 开始，到 end 结束的数字序列(不含 end 本身)

- `range(5)`: 0, 1, 2, 3, 4

`range(start, end)`: 获取一个从 start 开始，到 end 结束的数字序列(不含 end 本身)

- `range(2, 8)`: 2, 3, 4, 5, 6, 7

`range(start, end, step)`: 获取一个从 start 开始，到 end 结束的数字序列，step 为步长(不含 end 本身)

- `range(0, 10, 2)`: 0, 2, 4, 6, 8

```python
# 计算 100-500 之间所有 3 的倍数的数字之和
total = 0

for i in range(100, 501)
  if i % 3 == 0:
      total += i
```

### 数据存储容器

::code-group

```python [数组(列表)]
# 定义
s = [元素1, 元素2, 元素3, ...]

# 访问
print(s[0])
print(s[-2])

# 修改
s[1] = 修改值

# 删除指定位置的值
del s[2]
```

::

::tip

从前向后(正向索引)，下标从 0 开始；从后向前(反向索引)，下标从 -1 开始

::
