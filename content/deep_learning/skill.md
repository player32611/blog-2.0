## Skill 在 AI 能力栈的位置

L4 场景应用层（内容创作 / 办公自动化）

## SKILL.md 结构

**NAME**: 名称，小写字母 + 数字 + 连字符

**DESCRIPTION**: 简介，含触发词 + Use when

**TRIGGER**: 触发词，中英文至少各 2 个

**ABILTIES**: 能力，简洁明确的输入输出

**OUTPUT**: 输出，可被解析的结构化

```md
---
name: hello-skill
description: 当用户说"你好 / hello / hi / 打个招呼"时触发，使用星火 Lite 模型生成一句 30 字以内的中文问候语。Use when the user says hi / hello / great.
---

# hello-skill

## 能力

调用讯飞星火 Lite 接口，根据用户输入语言返回对应问候语。

## 输入

- 文本：用户消息
```

### DESCRIPTION

description = 决定触发的唯一依据，最长 1024 字符 + 第三人称写法 + 包含触发词 + Use when

## Skill 能力边界

### Skill 适合场景

- **内容生成**：PPT 生成、文章配图、小说写作

- **信息抽取**：会议纪要、简历解析、合同条款提取

- **数据处理**：表格整理、JSON 转换、批量改名

- **知识服务**：八股文刷题、面试陪练、英语口语

- **工作流编排**：日报生成、自动周报、跨工具调度

### Skill 不适合场景

- **强实时性（毫秒级）**：直接 API + 前端

- **大规模并发**：异步队列 + 缓存

- **严格权限/合规**：企业内私有 Skill + RBAC

- **主观审美（品牌设计）**：人 + Skill 协同

- **需要真实世界操作**：RPA + Skill

::tip

判断需求该不该做成 Skill：
**能用 1 句话描述输入 -> 输出**（80% 是 Skill 该做的）

::

## 优秀 Skill 质量标准

- **场景化**：解决具体真实痛点，不是"通用 AI 助手"（程序员周报/会议纪要）

- **触发词详尽**：中英文 + 同义词 + Use when 场景（15+ 触发词为佳）

- **端到端**：一句话拿到最终产物，无需手动串联（一条命令 = 全部）

- **成本可控**：模型选型合理，Lite / 蒸馏模型（简单任务用 Lite）

- **结构化输出**：JSON / Markdown / Word，可解析、和二次处理（不要自由文本）

- **插件化**：核心能力稳定，上层玩法可插拔

- **文档规范**：SKILL.md 完整，README + 示例 + 边界（至少 1 个用例）

- **可被调用**：在 SkillHub 发布，可被 AstronClaw / Loomy 调用（不只在本地能跑）
